# Cyber-Rover-Pro.
Cyber Rover Pro  Cyber Rover Pro è un controller avanzato per robot ESP32 con HUD futuristica. Include un simulatore 3D sincronizzato, telemetria in tempo reale per monitorare voltaggio e corrente, e gestione luci hardware. Trasforma il browser in una stazione di comando immersiva per una guida precisa e scenografica, senza app esterne.
